1. La forma general

Toda función cuadrática se puede escribir como:

f(x) = ax² + bx + c    con a ≠ 0

Su gráfica es una parábola: abre hacia arriba si a > 0 y hacia abajo si a < 0. El valor de a controla qué tan "estrecha" es la parábola.

2. El vértice

El punto más importante de la parábola es el vértice. Usando la forma canónica:

f(x) = a(x − h)² + k  ⟹  vértice V(h, k)

Desde la forma general, el vértice se calcula con:

h = −b / (2a)

3. Intersecciones

IntersecciónCómo se calcula
Con el eje yf(0) = c
Con el eje x (raíces)Resolver ax² + bx + c = 0 (factorización, fórmula cuadrática o gráfica)

Fórmula cuadrática:

x = (−b ± √(b² − 4ac)) / (2a)

El discriminante Δ = b² − 4ac decide el número de raíces reales:

ΔRaíces reales
Δ > 0Dos raíces distintas
Δ = 0Una raíz doble (toca el eje)
Δ < 0Ninguna (raíces complejas)

4. Ejemplo resuelto (estilo IB)

Sea f(x) = x² − 4x + 3. Encuentra el vértice y las raíces.

Vértice: h = −(−4)/(2·1) = 2, k = f(2) = 4 − 8 + 3 = −1 ⟹ V(2, −1)

Raíces: x² − 4x + 3 = (x − 1)(x − 3) = 0 ⟹ x = 1 y x = 3

Discriminante: Δ = 16 − 12 = 4 > 0 ⟹ dos raíces reales ✔
